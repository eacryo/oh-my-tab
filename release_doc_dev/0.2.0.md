# 0.2.0 Dev

## What's New

- Status-bar controls for services, shortcut mode, thumbnail/icon-only mode, and cache clearing.
- Clipboard one-shot deletion, guarded system clipboard cleanup, and configurable 0–7 day expiry.
- Four-way cross-display window movement with snap preservation.
- Pointer locator, screen lock, configurable activation mode, and improved settings/menu synchronization.
