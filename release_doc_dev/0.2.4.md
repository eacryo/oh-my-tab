# 0.2.4 Dev

## What's New

- First-run guide with live permission status and clearer restart guidance; reopenable from About.
- The guide opens on every install and resumes the same step after a restart, crash, or force quit; Sparkle updates do not reopen it.
- Guide choices apply immediately; the clipboard step points at Option+V and picking thumbnails asks for Screen Recording on the spot.
- Fixed a crash when opening Settings from the guide.
- Clipboard history: a top-right close button matching the switcher's, and a fixed empty state after clearing a tall panel.
- Clipboard history is faster and copies less image data.
- Yellow-button-minimized and Command+H-hidden windows have separate options, off by default, with a slashed-eye badge.
- Windows with native tabs show as a single card.
- Fullscreen Spaces now share candidates only with their confirmed source desktop; unknown origins remain isolated, avoiding cross-desktop window leaks.
- Fixed the maximize shortcut (Option+Up) on grid-snapping apps and maximizing a window dragged off screen.
- Panel and cards: sized by the cards with fixed symmetric margins, plus smaller sizes for small screens.
- Config syntax errors no longer reset the settings in effect.
- Fixed the About page's inline update notice being cut off at the bottom: the page now grows so the whole release note can be scrolled to.
- The update notice distinguishes available, downloaded, and installing updates.
- Settings pages hold their layout across scrollbar styles.

# 0.2.4 Dev

## 开发版本说明

- 首次运行引导：实时显示权限状态、给出更清晰的重启指引，可从「关于」页面重新打开。
- 引导页每次安装都会打开，重启、崩溃或强制退出后回到同一步骤继续；Sparkle 更新不会重新打开它。
- 引导页选项一经点选立即生效；剪贴板那一步提示按 Option+V，选择缩略图会当场申请屏幕录制权限。
- 修复最后一步点「打开应用设置」崩溃的问题。
- 历史剪贴板：右上角新增与应用切换浮窗一致的关闭按钮，并修复清空后空状态提示消失的问题。
- 历史剪贴板响应更快，并减少图像数据复制。
- 新增“黄色按钮最小化窗口”和“Command+H 隐藏窗口”两个选项，默认关闭，缩略图带斜杠眼睛标记。
- 带标签页的窗口只显示一张卡片。
- 全屏 Space 仅与已确认的来源桌面共用候选；来源未知时保持隔离，避免跨桌面串窗。
- 修复 Option+↑ 在会吸附网格的应用上进入全屏，以及窗口拖出屏幕后“最大化”失效的问题。
- 浮窗高度由卡片决定、上下留白固定对称；小屏新增两档更小的卡片尺寸。
- 配置文件有语法错误时不再重置当前生效的设置。
- 修复“关于”页面内嵌更新说明被截断、底部滚不到的问题：页面会随内容增高，可完整查看更新说明。
- 更新提示区分“有可用更新”“已下载”“正在安装”。
- 设置页在不同滚动条样式下保持布局稳定。

# 0.2.4 Dev

## 開發版本說明

- 首次執行引導：即時顯示權限狀態、給出更清楚的重啟指引，可從「關於」頁面重新開啟。
- 引導頁每次安裝都會開啟，重新啟動、崩潰或強制結束後回到同一個步驟繼續；Sparkle 更新不會重新開啟它。
- 引導頁選項一經點選立即生效；剪貼簿那一步提示按 Option+V，選擇縮圖時會當場申請螢幕錄製權限。
- 修復最後一步點「打開應用程式設定」崩潰的問題。
- 剪貼簿歷史：右上角新增與應用程式切換浮窗一致的關閉按鈕，並修復清空後空狀態提示消失的問題。
- 剪貼簿歷史回應更快，並減少影像資料複製。
- 新增「點黃色按鈕最小化的視窗」和「Command+H 隱藏的視窗」兩個選項，預設關閉，縮圖帶斜線眼睛標記。
- 帶標籤頁的視窗只顯示一張卡片。
- 全螢幕 Space 僅與已確認的來源桌面共用候選；來源未知時保持隔離，避免跨桌面串窗。
- 修復 Option+↑ 在會吸附網格的應用程式上進入全螢幕，以及視窗拖出螢幕後「最大化」失效的問題。
- 浮窗高度由卡片決定、上下留白固定對稱；小螢幕新增兩檔更小的卡片尺寸。
- 設定檔有語法錯誤時不再重設目前生效的設定。
- 修復「關於」頁面內嵌更新說明被截斷、底部捲不到的問題：頁面會隨內容增高，可完整檢視更新說明。
- 更新提示區分「有可用更新」「已下載」「正在安裝」。
- 設定頁在不同捲動條樣式下保持版面穩定。
