# 0.3.0 Dev

## Updates

- Add configurable Finder context-menu actions to create files, open a terminal, and copy paths.
- Use Control+Tab for the switcher. Choose the modifier in the onboarding guide, settings window, or menu bar.
- Edit window controls and quick actions in a shared key bindings list with a master switch.
- Bind actions to restore the previous window size, hide or show all windows, or open a small Finder window.
- Enable optional Command+W / M / H / Q actions for the highlighted switcher card.
- Export settings to a file and import them on this or another Mac.
- Pause clipboard recording or exclude copies from selected apps.
- Drag the clipboard picker by its top bar. Adjust image row height and view entry metadata in the redesigned clipboard detail panel.
- Adjust keystroke display width and height. Key combinations now use separate keycaps.
- Hide the menu bar icon. Open the settings window from gears on the switcher, clipboard picker, and keystroke display.
- The switcher highlights the whole card. Turn off the footer window title to remove the footer strip.
- The settings window uses a new layout. Sidebar labels follow the selected language.
- Install without an `.app` bundle through `scripts/install-unbundled.sh`. A launchd job starts the app at login. This mode does not support automatic updates.

# 0.3.0 Dev

## 更新说明

- 新增可配置的 Finder 右键菜单，支持新建文件、打开终端和复制路径。
- 切换器支持 Control+Tab。可在引导、设置窗口或菜单栏选择修饰键。
- 窗口控制与快捷操作合并为按键绑定列表，由总开关控制。
- 新增绑定动作：恢复之前的窗口尺寸、隐藏或显示所有窗口、打开 Finder 小窗口。
- 可为切换器高亮卡片启用 Command+W / M / H / Q 操作。
- 支持将设置导出为文件，并在本机或另一台 Mac 导入。
- 剪贴板历史支持暂停记录，也可排除指定应用的复制内容。
- 剪贴板选择器支持拖动顶栏和调整图片行高。剪贴板详情面板重新编排条目元数据。
- 按键显示支持调整宽高。组合键改用独立键帽。
- 支持隐藏菜单栏图标。切换器、剪贴板选择器和按键显示的齿轮可打开设置窗口。
- 切换器高亮整张卡片。关闭底栏窗口标题后，浮窗移除底栏。
- 设置窗口采用新布局。侧边栏标签随所选语言变化。
- 新增无 `.app` 包安装方式，使用 `scripts/install-unbundled.sh` 安装。launchd 任务在登录时启动应用。此方式不支持自动更新。

# 0.3.0 Dev

## 更新說明

- 新增可設定的 Finder 右鍵選單，支援新增檔案、開啟終端機和複製路徑。
- 切換器支援 Control+Tab。可在引導、設定視窗或選單列選擇修飾鍵。
- 視窗控制與快捷操作合併為按鍵綁定清單，由總開關控制。
- 新增綁定動作：恢復之前的視窗尺寸、隱藏或顯示所有視窗、開啟 Finder 小視窗。
- 可為切換器反白卡片啟用 Command+W / M / H / Q 操作。
- 支援將設定匯出為檔案，並在本機或另一台 Mac 匯入。
- 剪貼簿歷史支援暫停記錄，也可排除指定應用程式的複製內容。
- 剪貼簿選擇器支援拖曳頂欄和調整圖片列高。剪貼簿詳細資訊面板重新編排項目中繼資料。
- 按鍵顯示支援調整寬高。組合鍵改用獨立鍵帽。
- 支援隱藏選單列圖示。切換器、剪貼簿選擇器和按鍵顯示的齒輪可開啟設定視窗。
- 切換器反白整張卡片。關閉底欄視窗標題後，浮窗移除底欄。
- 設定視窗採用新版面。側邊欄標籤隨所選語言變化。
- 新增無 `.app` 套件安裝方式，使用 `scripts/install-unbundled.sh` 安裝。launchd 任務在登入時啟動應用程式。此方式不支援自動更新。
