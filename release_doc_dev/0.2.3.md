# 0.2.3 Dev

## What's New

- Added recovery guidance for users upgrading from 0.2.1 or 0.2.2 whose permissions need to be reauthorized. Accessibility is required for the global shortcut and window switching; Screen Recording is required for window thumbnails. In both permission lists, select the old Oh-My-Tab Dev entry and click **−** to remove it, then click **+** to add the updated Dev app and enable both permissions. Restart Oh-My-Tab Dev afterward.

# 0.2.3 Dev

## 开发版本说明

- 为从 0.2.1 或 0.2.2 Dev 升级后需要重新授权的用户提供了恢复指引。辅助功能用于全局快捷键和窗口切换，屏幕录制用于窗口缩略图。请在“辅助功能”和“屏幕录制”两个权限列表中分别选中旧版 Oh-My-Tab Dev，点 **−** 删除；再点 **+** 添加新版 Dev 应用并开启两项权限，最后重新启动 Oh-My-Tab Dev。
