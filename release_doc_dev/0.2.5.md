# 0.2.5 Dev

## What's New

- Clipboard history is now encrypted at rest: the history file, the original image bytes and the previews are sealed with AES-256-GCM under a random key kept in this Mac's login keychain, so the copies on disk are unreadable without it. The store's metadata (file names, sizes, timestamps) stays visible, and an existing history is converted to the encrypted form on first launch.
- When the key cannot be read — access denied, the prompt cancelled, or a locked keychain — the feature is unavailable: nothing is recorded (there is no in-memory fallback), and the settings page, the history panel and a system notification all say why, with a "Grant Keychain Access" action on the two in-app surfaces that asks for the keychain password once.
- Clipboard history is always written to disk while the feature is on, so it survives a restart without a second switch; the old "Save clipboard history to disk" option is gone, and existing configs keep loading.
- New "Clear history on quit or shutdown" option (off by default): with it on, quitting deletes the history file and the cached image data, so the session leaves nothing behind. It covers Command+Q, the menu's Quit, logout and shutdown; a crash or a force quit cannot run it.
- Turning clipboard history off now clears the saved records too, and the option says so.
- The picker's two clear actions now clear only what is on screen — the selected category, or the search results while a query is active — and their labels name that scope.
- The clipboard history shortcut is now configurable.
- The first-run guide no longer asks whether to save to disk; it states where history is kept instead.
- New panel material setting: liquid glass, frosted glass or opaque, with the text colour chosen for the material in use and verified on rendered pixels; floating panels also draw an outline and an elevation shadow.
- New thumbnail-size setting: automatic, or a fixed percentage.
- New keystroke display (opt-in): a draggable, hover-protected overlay with an initial position that shows each key separately, styles the modifier's release, follows theme changes, and stays quiet while secure input is active.
- New smooth-scrolling mode for the mouse wheel, with inertia.
- Fullscreen windows show a scrimmed badge on their switcher thumbnail.
- Hover tooltips are now drawn by the app itself: they appear immediately and match the rest of the UI.
- The UI design system — semantic colours, the type scale, the 4px spacing grid, radii, elevation and animation durations — now covers every surface, and text layout is language-tolerant, so long strings no longer clip in any of the three languages.
- Legibility fixes in dark mode: clipboard and glass colours, link text and tips.
- Cross-desktop switching is faster (the raise is submitted immediately) and reads the window state the WindowServer reports; cards stay scoped to their own Space, and floating windows are admitted only when the WindowServer reports an ordinary window.
- The selected card is scrolled into view, and the footer's selection ring no longer sticks to the last row.
- Reopening the already-running app (for example from Launchpad or the Dock) brings its Settings window forward.
- Fixes: a crash from over-releasing Cocoa objects, our own event-tap teardown being mistaken for the user disabling input, the settings dropdown keeping its focus ring after closing, a silent settings keystroke, and the first-run guide not following the appearance setting.

# 0.2.5 Dev

## 开发版本说明

- 剪贴板历史现在**加密落盘**：历史文件、图片原始字节与预览图都用 AES-256-GCM 封装，密钥是一把随机值、保存在本机登录钥匙串里，因此磁盘上的副本没有它读不出来。存储的元数据（文件名、大小、时间戳）仍然可见；已有的历史会在首次启动时转换为加密形式。
- 拿不到密钥时（访问被拒、授权框被取消、钥匙串被锁）功能**不可用**：什么都不记录（也没有内存回退），设置页、历史面板与一条系统通知都会说明原因，其中两个应用内界面各有一个「授予钥匙串访问」动作，会要求输入一次钥匙串密码。
- 剪贴板历史在功能开启期间一律写入磁盘，重启后自动保留，不再需要单独开关；旧的「保存剪贴板历史记录到磁盘」选项已移除，老配置照常加载。
- 新增「退出应用或关机后清除历史记录」选项（默认关闭）：打开后退出应用会删除历史文件与已缓存的图片数据，退出后不留记录。Cmd+Q、菜单退出、注销与关机都会执行；崩溃或强制退出无法执行。
- 关闭剪贴板历史现在会一并清除已保存的记录，选项说明也已注明。
- 历史剪贴板右上角的两个清除按钮现在只清除当前屏幕上的内容（所选分类，或有关键词时的筛选结果），按钮文字会写明范围。
- 历史记录快捷键现在可以自定义。
- 首次运行引导不再询问是否保存到磁盘，改为说明历史记录保存在哪里。
- 新增面板材质设置：液态玻璃、磨砂玻璃或不透明；文字颜色按当前材质选取，并在渲染像素上验证过。浮动面板还新增了描边与投影层次。
- 新增缩略图大小设置：自动，或固定百分比。
- 新增按键显示浮窗（可选开启）：可拖动、悬停时防误触，有初始位置；每个键单独显示，并对修饰键的松开着色；跟随主题切换，安全输入生效时保持安静。
- 新增鼠标滚轮平滑滚动模式，带惯性。
- 全屏窗口在切换浮窗的缩略图上会显示一层遮罩徽标。
- 悬停提示改由应用自己绘制：立刻出现，并且与界面其余部分风格一致。
- UI 设计系统（语义色、字号阶梯、4px 间距网格、圆角、层次与动画时长）覆盖到每个表面；文本布局对语言更宽容，三种语言的长文案都不再被裁断。
- 深色模式可读性修复：剪贴板与玻璃配色、链接文字与提示文案。
- 跨桌面切换更快（不再等待目标，直接提交置顶）并改为读取 WindowServer 报告的窗口状态；卡片只归属自己所在的 Space；只有 WindowServer 判定为普通窗口的浮动窗口才会被纳入。
- 选中的卡片会自动滚动到可见区域，页脚最后一行不再残留选中环。
- 重新打开已在运行的应用（例如从启动台或程序坞）会把设置窗口带到前台。
- 修复：过度释放 Cocoa 对象导致的崩溃；把自家事件 tap 的拆除误判为用户关闭输入；设置里的下拉框关闭后残留焦点环；设置界面的某次按键被吞掉；首次运行引导不跟随外观设置。

# 0.2.5 Dev

## 開發版本說明

- 剪貼簿歷史現在**加密落盤**：歷史檔案、圖片原始位元組與預覽圖都以 AES-256-GCM 封裝，金鑰是一把隨機值、保存在本機登入鑰匙圈裡，因此磁碟上的副本沒有它讀不出來。儲存的詮釋資料（檔名、大小、時間戳）仍然可見；既有的歷史會在首次啟動時轉換為加密形式。
- 拿不到金鑰時（存取被拒、授權框被取消、鑰匙圈被鎖）功能**無法使用**：什麼都不記錄（也沒有記憶體回退），設定頁、歷史面板與一則系統通知都會說明原因，其中兩個應用程式內介面各有一個「授予鑰匙圈存取」動作，會要求輸入一次鑰匙圈密碼。
- 剪貼簿歷史在功能開啟期間一律寫入磁碟，重新啟動後自動保留，不再需要另一個開關；舊的「儲存剪貼簿歷史記錄到磁碟」選項已移除，舊設定檔照常載入。
- 新增「結束應用程式或關機後清除歷史記錄」選項（預設關閉）：開啟後結束應用程式會刪除歷史檔案與已快取的影像資料，結束後不留記錄。Cmd+Q、選單結束、登出與關機都會執行；崩潰或強制結束無法執行。
- 關閉剪貼簿歷史現在會一併清除已儲存的記錄，選項說明也已註明。
- 剪貼簿歷史右上角的兩個清除按鈕現在只清除目前畫面上的內容（所選分類，或有關鍵字時的篩選結果），按鈕文字會寫明範圍。
- 歷史記錄快速鍵現在可以自訂。
- 首次執行引導不再詢問是否儲存到磁碟，改為說明歷史記錄儲存在哪裡。
- 新增面板材質設定：液態玻璃、磨砂玻璃或不透明；文字顏色依目前材質選取，並在渲染像素上驗證過。浮動面板還新增了描邊與陰影層次。
- 新增縮圖大小設定：自動，或固定百分比。
- 新增按鍵顯示浮窗（可選開啟）：可拖曳、懸停時防誤觸，有初始位置；每個鍵單獨顯示，並為修飾鍵的放開著色；跟隨主題切換，安全輸入生效時保持安靜。
- 新增滑鼠滾輪平滑滾動模式，帶慣性。
- 全螢幕視窗在切換浮窗的縮圖上會顯示一層遮罩徽標。
- 懸停提示改由應用程式自己繪製：立刻出現，並且與介面其餘部分風格一致。
- UI 設計系統（語意色、字級階梯、4px 間距網格、圓角、層次與動畫時長）涵蓋到每個表面；文字排版對語言更寬容，三種語言的長文案都不再被裁切。
- 深色模式可讀性修正：剪貼簿與玻璃配色、連結文字與提示文案。
- 跨桌面切換更快（不再等待目標，直接提交置頂）並改為讀取 WindowServer 回報的視窗狀態；卡片只歸屬自己所在的 Space；只有 WindowServer 判定為一般視窗的浮動視窗才會被納入。
- 選取的卡片會自動捲動到可見區域，頁尾最後一列不再殘留選取環。
- 重新開啟已在執行的應用程式（例如從啟動台或 Dock）會把設定視窗帶到前景。
- 修正：過度釋放 Cocoa 物件導致的崩潰；把自家事件 tap 的拆除誤判為使用者關閉輸入；設定中的下拉選單關閉後殘留焦點環；設定介面的某次按鍵被吞掉；首次執行引導不跟隨外觀設定。
