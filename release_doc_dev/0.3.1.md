# 0.3.1 Dev

## New Features

- Liquid Glass style update.
- Add a switch that opens the clipboard history in the middle of the screen or near the cursor.
- Move the expand-details button from the top right of the clipboard history into each entry.
- Allow dragging the keystroke display from any position except the settings button.
- Add space between a settings section heading and the card below it.
- Match the clipboard entry action icons to a thinner outline set.
- Restore the backspace symbol in the clipboard delete shortcut hint.

## Bug Fixes

- Fix a memory leak when copying images.
- Fix the soft-wrap switch that could not be turned on or off.
- Fix the clipboard search field ignoring clicks when the panel uses the frosted or glass material.
- Fix the clipboard options popover running past the edge of the panel.
- Fix the truncated title in the update check.
