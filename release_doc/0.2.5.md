# 0.2.5 

## What's New

- Clipboard history no longer keeps records in memory only: it is always written to disk encrypted, with the key kept in the login keychain.
- Added a notice when the key cannot be read.
- New "Clear history on quit or shutdown" option (off by default).
- New "Use a separate Clear All button" switch for the history panel; the regular clear button removes only unpinned entries.
- New settings: panel material (Liquid Glass, Frosted glass or Opaque), thumbnail size and smooth mouse-wheel scrolling.
- New opt-in Keystroke Display: a draggable overlay that shows each key separately and stays quiet while secure input is active.
- New "Always show windows from other desktops" switch.
- Window switching is faster.
- Fixed a number of known issues.

# 0.2.5 

## 更新说明

- 移除历史剪贴板纯内存模式，统一加密落盘，密钥保存在登录钥匙串中。
- 增加未获取到密钥时的提示。
- 新增「退出应用或关机后清除历史记录」选项（默认关闭）。
- 历史剪贴板增加独立的清除全部按钮开关，默认按钮只清除未置顶项。
- 新增设置：面板材质（液态玻璃、磨砂玻璃或不透明）、缩略图大小、鼠标滚轮平滑滚动。
- 新增按键显示浮窗（可选开启）：可拖动，每个键单独显示，安全输入生效时保持安静。
- 增加了始终显示其他桌面的窗口的开关。
- 优化窗口切换的速度。
- 修复了一些已知问题。

# 0.2.5 

## 更新說明

- 剪貼簿歷史不再有純記憶體模式：一律加密寫入磁碟，金鑰保存在登入鑰匙圈中。
- 增加拿不到金鑰時的提示。
- 新增「結束應用程式或關機後清除歷史記錄」選項（預設關閉）。
- 新增「使用獨立的清除全部按鈕」開關；一般清除按鈕只清除未置頂的項目。
- 新增設定：面板材質（液態玻璃、磨砂玻璃或不透明）、縮圖大小、滑鼠滾輪平滑捲動。
- 新增按鍵顯示浮窗（可選開啟）：可拖曳，每個鍵單獨顯示，安全輸入生效時保持安靜。
- 新增「始終顯示其他桌面的視窗」開關。
- 最佳化視窗切換速度。
- 修正了一些已知問題。
