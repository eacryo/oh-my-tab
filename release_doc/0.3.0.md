# 0.3.0

## What's New

- Added a configurable Finder context menu with three items: create a new file, open the folder in a terminal, and copy its path.
- Control+Tab is now available as the switcher modifier, next to Command+Tab and Option+Tab.
- Window controls and quick actions now share one Key Bindings list, gated by a single master switch.
- The list gained restore-previous-size, hide-all-windows and show-all-windows, plus "Open Finder (small window)" beside the maximized one.
- Optional Command+W / M / H / Q actions on the highlighted switcher card, each with its own switch.
- Export settings to a file and import them on this or another Mac.
- Pause clipboard recording, or exclude selected apps from the history.
- Drag the clipboard picker by its top bar, and set image entries to 1–3 rows tall.
- The clipboard detail panel lays its metadata out in two columns.
- Keystroke Display gained an input source choice, a screen choice and a maximum-length slider.
- Hide the menu bar icon, and open settings from the gear on the switcher, the clipboard picker and the keystroke panel.
- The switcher now highlights the whole card. Turning off the footer window title removes the footer band.
- The settings window uses a new layout, and its sidebar labels follow the selected language.
- Install without an `.app` bundle through `scripts/install-unbundled.sh`. A launchd job starts the app at login; this mode does not support automatic updates.
- Fixed a number of known issues.

# 0.3.0

- 修复了一些已知问题。

# 0.3.0

## 更新說明

- 新增可設定的 Finder 右鍵選單，包含三項：新增檔案、在終端機中開啟、複製路徑。
- 切換器新增 Control+Tab 修飾鍵，與 Command+Tab、Option+Tab 並列可選。
- 視窗控制與快捷操作合併為統一的按鍵綁定清單，由一個總開關控制。
- 清單新增還原先前的視窗尺寸、隱藏所有視窗、顯示所有視窗，以及「開啟 Finder（小視窗）」。
- 可為切換器反白卡片啟用 Command+W / M / H / Q 操作，每項各有獨立開關。
- 支援將設定匯出為檔案，並在本機或另一台 Mac 匯入。
- 剪貼簿歷史支援暫停記錄，也可排除指定應用程式的複製內容。
- 剪貼簿選擇器可拖曳頂欄移動，圖片項目高度可設為 1–3 列。
- 剪貼簿詳細資訊面板的中繼資料改為兩欄排列。
- 按鍵顯示新增輸入來源、顯示螢幕和最大長度三個選項。
- 支援隱藏選單列圖示。切換器、剪貼簿選擇器和按鍵顯示的齒輪可開啟設定視窗。
- 切換器改為反白整張卡片。關閉底欄視窗標題後，底欄一併隱藏。
- 設定視窗採用新版面。側邊欄標籤隨所選語言變化。
- 新增無 `.app` 套件安裝方式，使用 `scripts/install-unbundled.sh` 安裝。launchd 任務在登入時啟動應用程式，此方式不支援自動更新。
- 修正了一些已知問題。
