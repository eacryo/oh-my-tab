# 0.1.9

## What's New

- Redesigned Settings window: clearer sidebar and control styling, animated dropdowns, and tooltips that explain why a control is disabled.
- Changes apply immediately: most settings take effect the moment you adjust them, no need to reopen Settings.
- Restore defaults per page: each Settings page can reset its options with one click, with a clear confirmation.
- New window-switching shortcut: use Option + Arrow keys to move between windows.
- Follows system dark mode: the switcher and Settings refresh instantly when the appearance changes.
- Clearer update checks: a larger button with a loading animation.

## Improvements & Fixes

- More reliable thumbnails: suspended apps no longer show blank previews, and switching desktops (Show Desktop) no longer captures an empty frame.
- No more truncated text in Settings: long labels and dropdown options are fully readable.
- More consistent visuals: switcher footer text, sidebar hover animation, and mouse-mapping icons now look uniform.
- Fixed several layout and refresh issues (window position after refresh, appearance switching, and more).

# 0.1.9

## 更新内容

- 设置界面重新设计：更清晰的侧栏与控件、新的下拉动画；被禁用的选项会说明原因。
