# 0.2.0

## What's New

- More controls from the status bar: toggle core services, switch between Cmd+Tab and Option+Tab, change thumbnail/icon-only mode, and clear caches.
- Clipboard history improvements: one-shot paste-and-delete, optional guarded cleanup of the matching system clipboard item, and a 0–7 day expiry slider.
- Window management shortcuts: Option+Shift+Arrow moves windows across displays, with four-way movement that preserves maximized and snapped layouts.
- New convenience actions: double-Control locates the pointer, and Option+L locks the screen. Window activation can now be set to hover or click.

## Improvements & Fixes

- Settings and status-bar controls now stay synchronized while the Settings window is open.
- More reliable runtime configuration, persistence, event handling, and single-instance behavior.
- Refined clipboard details, settings layout, hover feedback, and thumbnail refresh behavior.

- 优化剪贴板详情、设置布局、悬停反馈和缩略图刷新体验。
