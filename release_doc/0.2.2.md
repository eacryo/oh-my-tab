# 0.2.2

## What's New

- Thumbnail cards can show the app name alongside the window title, without repeating it when both names match.
- Linear pointer tracking now has an adjustable speed from 0 to 10. Double-click the slider to reset it; the default speed is 1.00, and the original system pointer settings are restored when the app quits.
- Software-injected mice, such as Deskflow's virtual pointer, now have a separate device profile for scrolling and button mappings. Mouse button recording is more reliable.
- Added **Export Logs** to Settings and localized native system panels for English, Simplified Chinese, and Traditional Chinese.
- Settings now hide controls that do not apply and use more consistent spacing. Dropdown menus can open at full height even when they extend beyond the Settings window, and the window corners better match macOS 27's Liquid Glass style.
- Improved window switching by filtering attached child windows, limiting waits on unresponsive apps, and keeping card-close animations in sync with overlay resizing.
- Improved resilience around Accessibility calls, Objective-C callbacks, and mouse reconnections.
- The production app is now signed with our Apple Developer ID and notarized by Apple, allowing Gatekeeper to verify its source and notarization instead of blocking it as an unidentified or unnotarized app.

# 0.2.2

## 更新内容

- 缩略图卡片可同时显示应用名称和窗口标题；两者相同时只显示一次。
- 线性指针跟踪新增可调速度，范围为 0–10。双击滑块可恢复默认值；默认速度为 1.00，退出应用时会恢复原有的系统指针设置。
- 软件注入的鼠标（例如 Deskflow 的虚拟指针）现在拥有独立设备配置，可单独设置滚动和按键映射；按键映射录制也更加稳定。
- 设置中新增“导出日志”，并为英文、简体中文和繁体中文系统本地化原生系统面板。
- 设置页会隐藏不适用的控件，页面间距也更加统一。下拉菜单即使超出设置窗口，也可以完整展开；窗口圆角也更贴合 macOS 27 的 Liquid Glass 风格。
- 改进窗口切换体验：过滤附属子窗口、限制无响应应用造成的等待，并让卡片关闭动画与浮窗尺寸调整保持同步。
- 提升辅助功能调用、Objective-C 回调和鼠标重新连接时的稳定性。
- 正式版现已使用 Apple Developer ID 签名并通过 Apple 公证，Gatekeeper 可以验证应用来源和公证状态，避免因无法识别开发者或缺少公证而阻止打开。

# 0.2.2

## 更新內容

- 縮圖卡片可同時顯示應用程式名稱和視窗標題；兩者相同時只顯示一次。
- 線性指標追蹤新增可調速度，範圍為 0–10。雙擊滑桿可恢復預設值；預設速度為 1.00，結束應用程式時會恢復原有的系統指標設定。
- 軟體注入的滑鼠（例如 Deskflow 的虛擬指標）現在有獨立裝置設定，可分別設定捲動和按鍵映射；按鍵映射錄製也更加穩定。
- 設定中新增「匯出日誌」，並為英文、簡體中文和繁體中文系統本地化原生系統面板。
- 設定頁會隱藏不適用的控制項，頁面間距也更加一致。下拉式選單即使超出設定視窗，也可以完整展開；視窗圓角也更貼合 macOS 27 的 Liquid Glass 風格。
- 改進視窗切換體驗：過濾附屬子視窗、限制無回應應用程式造成的等待，並讓卡片關閉動畫與浮窗尺寸調整保持同步。
- 提升輔助使用呼叫、Objective-C 回呼和滑鼠重新連線時的穩定性。
- 正式版現已使用 Apple Developer ID 簽署並通過 Apple 公證，Gatekeeper 可以驗證應用程式來源和公證狀態，避免因無法識別開發者或缺少公證而阻止開啟。
