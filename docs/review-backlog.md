# 审查积压（Review backlog）

在 *Review budget and triage*（AGENTS.md）下判定为有效但超出范围的发现，以及没有任何一轮关闭的已知缺口。这里没有任何一条是在声称行为正确——每条都是一次决定：把这项工作排期，而不是在暴露它的那次改动里顺手做掉。

在一轮被分诊时就补记，不要拖后：轮次、严重度、为何延后，以及把它带回来的触发条件。它的工作落地后删掉该条，并在提交或发布说明里讲明。
