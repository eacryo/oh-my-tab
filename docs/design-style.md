# 设计风格（Design Style）

这是 oh-my-tab 所有自绘界面的规范性文档。改动任何用户能看到的东西之前，先读这一份。英文版见
`docs/design-style-en.md`。

以下规则改编自 Meta 的 [Astryx](https://astryx.atmeta.com/docs/principles) 设计系统（语义 token、
每个维度只有一把尺子、按层级划分 surface、有目的的动效），以及本项目已经遵循的 macOS 惯例。当本文
与现有实现冲突时，**以本文为准，现有实现即为缺陷**。

只有在平台强制时才可以偏离（AppKit 自己绘制的控件、系统提供的取值、用户自己的内容）。偏离时必须在
代码旁写明原因。

---

## 1. 适用范围

| 适用 | 不适用 |
| --- | --- |
| 设置窗口（侧边栏、页面、卡片、行、控件、底部按钮） | 我们不绘制的原生 AppKit 外观：红绿灯、菜单栏菜单、系统面板 |
| 应用切换浮窗（卡片、标题、选中环、页脚、滚动条、关闭/取消入口） | 原样呈现的用户数据：窗口标题、应用名、剪贴板内容、文件路径 |
| 剪贴板选择器与详情面板 | 第三方窗口缩略图 |
| 引导页、更新提示、通知、tooltip | 未改造的 `NSAlert` / `NSPanel` 系统模板 |
| HUD：按键显示、指针定位、快捷操作反馈 | |

左列全部属于「外观」（chrome），必须使用下文的 token。右列属于「数据」：由布局规则摆放，但内容本身
绝不重新配色或改写。

## 2. 原则

1. **只用语义 token，调用点不写原始值。** 视图请求的是「卡片上的次要文字」，不是 `#73737A`。
2. **每个维度只有一把尺子。** 字号、间距、圆角各有一把固定的短梯子。不在梯子上的取值是 bug，不是特例。
3. **层级来自 surface 和描边，不来自阴影。** elevation 只表达「它浮在别的元素之上」。
4. **动效用来解释变化，绝不拖延操作。** 只做入场/退场，不做 hover 和高频状态。
5. **文字必须可读。** 对比度是量出来的，不是估出来的。
6. **可见即本地化、可见即可读。** 屏幕上不出现内部标识符或配置键；中文本地化界面里不写死英文。用户自己的颜色值只可作为颜色选择器的说明文字显示十六进制。

不得内联十六进制值。

10.61:1、深色 10.22:1。

### 3.2 Surface 层级

`window_bg` → `sidebar_bg` → `card_bg` → 弹出面板。每一层与它背后的那层在视觉上可区分，且任何一层不得
承担两种用途。窗口背景上一组成组的行就是一张卡片，不是另一种底色的窗口。

### 3.3 对比度下限

用**合成后**（带 alpha 混合后）的颜色，对元素实际所在的 surface 测量。

**文字**

| 角色 | 下限 | 浅色实测 | 深色实测 |
| --- | --- | --- | --- |
| `text_primary` | 12:1 | 12.97:1（对 `window_bg`） | 15.63:1 |
| `text_secondary` | 7:1 | 8.19:1（对 `window_bg`） | 10.10:1 |
| `text_muted` | 4.5:1 | 5.16:1（对 `window_bg`）、5.53:1（对 `card_bg`） | 6.40:1 / 5.24:1 |
| `text_disabled` | 2.5:1 | 2.58:1（对 `window_bg`）、2.76:1（对 `card_bg`） | 4.11:1 / 3.37:1 |

`text_primary` 是整个调色板余量最小的一个。主文字色或 `window_bg` 变化时必须重测；不要为了「更好看」
而单独把它加深。

**非文字**

分两条，因为它们回答的是不同的问题。

1. **仅靠颜色承载状态 —— 下限 3:1。** 焦点环、选中环、状态点、错误/警告描边，以及任何「去掉颜色就
   失去含义」的指示。accent 为 `#0A84FF`：对 `card_bg` **3.65:1**，对 `window_bg` 3.40:1。新增状态
   指示必须先实测再上线。
2. **结构性边界 —— 下限 1.2:1，属于记录在案的偏离。** 卡片描边、控件描边、分隔线、开关轨道，
   承载的是填充、形状、位置和标签**已经**表达的信息。它们低于 WCAG 1.4.11 的 3:1 是有意为之：
   在 `card_bg` 上达到 3:1 需要 `rgba(0,0,0,.42)`（即 `#949494`），会像一条又重又不像原生控件的边框。
   实测：`card_border` 对 `card_bg` **1.25:1**；开关关闭态轨道 `#C7C7CC`（浅）**1.68:1**、`#636366`
   （深）**2.33:1**。

   该偏离只在边界**不是控件的唯一标识**时成立。如果一个控件拿掉描边就认不出来——没有填充、没有
   标签、没有形状、旁边也没有图标——那它的描边必须做到 3:1，且应新增一个 `control_border` token，
   而不是去改 `card_border`。

开关是第 2 条的范例：开/关由滑块位置和 accent 填充表达，轨道颜色永远不是唯一信号。

新增 token 必须实测，不许目测。半透明颜色要按合成后的结果算，不能只看 alpha。

### 3.4 半透明

窗口和卡片背景可以半透明，以透出桌面形成玻璃感。设置页侧边栏使用不透明的 `sidebar_bg`，保证颜色稳定。**承载文字的表面必须足够不透明，保证上表在
最差背景下依然成立**。浮窗玻璃是例外：它是覆盖在任意内容之上的临时表面，其文字颜色必须按它能覆盖到的
最深和最浅背景来选。

浮动面板(切换器、剪贴板、按键显示)通过 `panel_material` 设置提供三种材质:

| 材质 | 表面 | 说明 |
| --- | --- | --- |
| `liquid-glass`(默认) | `NSGlassEffectView`,`glass_style`/`glass_tint` 子选项 | macOS < 26 退化为磨砂 |
| `frost` | `NSVisualEffectView`,behind-window,材质跟随主题 | 中性系统模糊;玻璃子选项不适用 |
| `opaque` | `window_bg` 填充,无模糊 | 系统开启「减弱透明度」时也是强制回退项 |

材质只改变面板内容背后的表面——文字颜色、间距、圆角与调色板完全遵循本文其余部分。

## 4. 文字

只有四档，其余都是 bug。

| 角色 | 字号 | 字重 | 颜色 | 说明 |
| --- | --- | --- | --- | --- |
| `page-title` | 26 | 700 | primary | 设置页标题，每页一个；字距 `-0.4` |
| `sidebar-title` | 20 | 700 | primary | 侧边栏顶部的应用名 |
| `section-header` | 12 | 600 | secondary | 卡片上方的分组标题 |
| `row-label` | 14 | 400 | primary | 设置行标签、列表主文字 |
| `control` | 14 | 400 | primary | 下拉值、输入框文字、按钮标题、行内次要值 |
| `caption` | 12 | 400 | muted | 行说明、版本号、空态、脚注 |

- 内置字重只用 400 / 600 / 700。600 给区块标题，700 给标题。显式配置的 `fonts.*_weight` 是浮窗的高级外观偏好，予以保留；旧版 500 默认值会迁移为 semibold。
- 数字读数（滑杆值、条数、字节数）使用等宽数字（tabular figures），避免切换时抖动。
- 行高：12pt 用 1.35，14pt 用 1.4，标题用 1.2。角色已定义行高时不得手工覆盖。
- 不要靠缩小字号来塞进控件。应该截断或挪走内容（见 §9）。
- About 页的版本号是 `caption`，不是一行数据：它属于页面副标题，不该占数值列。

### 4.1 浮窗文字

卡片标题、卡片应用名与页脚是全应用唯一可由用户缩放的文字。两个卡片 caption 共用
`layout.card_text_size`；页脚直接使用独立的 `fonts.status_bar_size` 设置。

| 角色 | 使用 `layout.card_text_size` | 有效字号 |
| --- | --- | --- |
| 卡片标题（`fonts.title_size`） | 是 | 缩放后 13…20pt |
| 卡片应用名（`fonts.app_name_size`） | 是 | 缩放后 13…20pt |
| 页脚（`fonts.status_bar_size`） | 否 | 配置值 13…20pt |

- **卡片 caption 共用一个倍率。** 改动 `layout.card_text_size` 时标题和应用名同步缩放，相对大小不得漂移。
- **钳制作用于缩放后的结果。** 卡片 caption 的 `fonts.*_size` 是基数而非最终字号：以 12pt 为基数时
  卡片标题落在 `card_text_size` 上；应用名按比例缩放，两者都钳在 13…20pt。
- **页脚独立。** 字号直接使用 `fonts.status_bar_size`，经 13…20pt 配置范围校验；不随卡片 caption 缩放。
- **任一 caption 行的行高不超过所在卡片高度的 1/3。**
- **caption 只有一行。** 放不下就省略号截断，绝不换行，也绝不把缩略图挤出卡片。

Markdown 更新说明的一级标题使用 `sidebar-title` 粗体，二级标题使用 `control` semibold。浮窗基数字号、共享倍率和结果钳制已在 `theme.rs` 实现；显式字重覆盖仍视为用户偏好。

## 5. 间距

基准 **4px**。允许的步进：`4 8 12 16 24 32`。2px 仅允许出现在控件**内部**几何（滑块内缩、发丝线偏移），
不得用于同级元素之间。

设置窗口的具名布局度量（全部落在网格上）：

| 度量 | 取值 | 位置 |
| --- | --- | --- |
| 侧边栏宽度 | 220 | `SETTINGS_SIDEBAR_WIDTH` |
| 侧边栏条目内缩 | 12 | `settings/sidebar.rs`（`btn_w = card_w - 24`） |
| 页面顶部留白 | 48 | `SettingsPageHeader::TOP_PADDING` |
| 页面底部留白 | 72 | `SettingsPageHeader::BOTTOM_PADDING` |
| 区块标题上方间距 | 24 | `SETTINGS_SECTION_HEADER_GAP` |
| 标题 → 卡片间距 | 4 | `SETTINGS_SECTION_CARD_GAP` |
| 行间距 | 8 | `SettingsLayout::row_gap` |
| 行高 52，控件高 32，垂直居中 | | `SettingsLayout` |
| 控件列 | 宽 200，右对齐，距卡片右边 16 | `SettingsLayout` |
| 卡片左右内边距 | 16 | 行构造函数（`label_x`、`SETTINGS_CONTROL_TRAILING_INSET`） |
| 卡片底部内边距 | 8 | `SettingsLayout::card_bottom_inset` |
| 行上方分隔线的间距 | 4 | `SEPARATOR_ABOVE_ROW_GAP` |
| 滑杆读数 | 宽 44，间距 8 | `SLIDER_READOUT_*` |

经验法则：**相关元素 8，分组之间 24，页面边缘 32–72。** 需要紧凑用小的那一档，需要分隔用大的那一档；
同一种间距绝不允许一会儿 12 一会儿 14。

## 6. 圆角

| Token | 取值 | 用于 |
| --- | --- | --- |
| `radius-control` | 8 | 按钮、输入框、下拉框、色块、列表项高亮、开关轨道的内部几何 |
| `radius-card` | 12 | 卡片、成组行容器、列表块、弹出项 |
| `radius-panel` | 16 | tooltip、下拉面板、HUD、通知卡片 |
| `radius-full` | 9999 | 胶囊：徽标、状态点、开关、滚动条滑块 |
| 窗口圆角 | 由平台决定（实测，当前为 26） | 设置窗口本身 |

**同心规则。** 有内边距的圆角容器，其内部元素的圆角为 `max(0, 外圆角 - 内边距)`。围绕卡片绘制的选中环
半径为 `卡片圆角 + 环内缩`，从而与卡片保持平行；绝不手工指定环半径。
切换器选中环的 `ring_inset` 为 3pt。

浮窗卡片圆角跟随 `appearance.corner_radius`，但最大为 `radius-panel`（16pt）。更大的配置值仍用于玻璃和窗口表面，
不会让切换器卡片变得过圆。窗口缩略图本身保持直角；关闭按钮和选中环从有效卡片半径派生，避免设置变化后残留过期几何。标题栏中的小应用图标使用 `radius-control`。

## 7. Elevation

四档。按**表面离页面多远**选，而不是按「阴影多重才好看」选。

| 档位 | 阴影 | 用途 |
| --- | --- | --- |
| `none` | —（仅描边） | 默认。行、卡片、行内提示、按钮 |
| `low` | `0 1px 2px rgba(0,0,0,.06)` | 需要与背景区分、但仍在文档流内的表面 |
| `med` | `0 4px 12px rgba(0,0,0,.10)` + 描边 | 浮在页面内容之上：popover、下拉菜单、tooltip |
| `high` | `0 12px 32px rgba(0,0,0,.18)` | 浮在整个界面之上：对话框、引导页、带遮罩的浮窗面板 |

中档 elevation 在 `theme.rs` 中由一组共享的黑色阴影、不透明度、模糊半径和垂直偏移表示；下拉菜单和 tooltip
共用这些常量。缩略图角标（全屏、最小化/隐藏）是承载白色符号的圆形 `badge_scrim` 圆片；圆片使用单独命名的
`symbol_shadow` 角色和共享几何常量；它是小尺寸对比辅助，不是表面 elevation。
该阴影的不透明度为 0.85、模糊半径为 2pt、垂直偏移为 −1pt。白色符号叠在纯白缩略图上的圆片之上实测对比度为
4.74:1，高于非文字指示器 3:1 的下限。

- 每个表面只用一档，绝不叠加阴影来「更浮」。
- 设置页里的卡片是 `none`：层级来自 `card_bg` + `card_border`。窗口内的卡片挂一层大范围柔光就是 bug，
  它暗示卡片浮在某个它并没有浮在之上的东西上面。
- 描边用 `card_border`，不要用阴影代替，也不要用更深的底色代替。
- 输入焦点使用内嵌 accent 环（2pt，见 §10），它不属于 elevation。卡片或缩略图块的选中态可以使用外侧 accent
  环；其外侧圆角按 §6 由卡片圆角和环内缩推导。

## 8. 动效

| Token | 取值 | 用途 |
| --- | --- | --- |
| `duration-fast` | 175 ms | 微交互；开关按压反馈使用组件专属时长 |
| `duration-medium` | 380 ms | 空间变化：面板开合、展开/收起、页面切换 |
| `ease-standard` | `cubic-bezier(0.24, 1, 0.4, 1)` | 除有明确理由外，所有动画 |
| 退场时长 | 入场时长的 0.75 倍，曲线相同 | 关闭面板、关闭对话框 |

规则：

- **上下文 UI 只做入场动画。** tooltip、hover 卡片、下拉菜单可以瞬间消失；面板、对话框、展开的行两个
  方向都做动画，且退场沿入场方向原路返回。
- **绝不动画化**：hover 填充、行高亮、用户连续移动中的选中、滚动，以及任何一分钟会触发多次的交互。
  这些必须瞬间完成。
- 动画不得阻塞输入：已经在动画的内容，只要可交互就保持可交互。
- 弹簧仅用于「物理手感本身就是目的」的地方（开关滑块、卡片关闭、面板回弹）。每个组件只用一条既定弹簧；
  不得在每个调用点微调 stiffness/damping；同一种手势在不同组件里不得用不同弹簧。
- **Reduce Motion 是强制的，且在动画发生时读取**，不能在启动时缓存：
  `NSWorkspace.accessibilityDisplayShouldReduceMotion` 为真时改为瞬时切换。所有动画表面都要处理，
  包括浮窗、页面切换和设置窗口外壳。

## 9. 组件

**设置行。** 左侧标签（14 / primary），右侧控件，右对齐到控件列。标签下可有一行可选 `caption`（12 / muted）。
一行一个概念。

- 控件高度恒为 32（单行）。放不下的值用省略号截断，并在 tooltip 里给出完整值——**控件绝不折成两行**。
- 行标签是名词短语，不是句子。解释性内容放到 caption 行。
- 行之间用卡片内通栏的 1px `separator` 分隔；首行和末行在卡片边缘处没有分隔线。

**卡片。** 用于成组的行。`radius-card` + `card_bg` + `card_border`，elevation `none`。一张卡片上方配一个
区块标题。如果某一行属于相邻分组，就不要为它单独包一张卡片。

**区块标题。** 12 / 600 / secondary，距卡片上方 24、下方 4。用陈述式短语，结尾不加冒号。

**按钮。** 三种角色：primary（accent 填充 + 白字）、secondary（card 底 + 描边）、destructive（红字/红边，
仅确认操作使用红底）。一个视图只有一个 primary。行内操作按钮高 32，右对齐到控件列。按钮的 hover/normal
配色**不得**用 `tag` 承载（见 `AGENTS.md`）。

**开关。** 38×22，滑块 18；开启 = `accent`，关闭轨道 = `switch_off_track`。整行不可点击，只有开关可点击。
滑块沿用弹簧计算出的稳定时长，最低 180 ms；按压反馈为 220 ms，沿用关键帧默认曲线。这些组件专属值优先于
通用的快速时长和缓动 token。滑块只在其 2pt 内缩范围内跟随。

**滑杆。** 连续滑杆——**不带刻度**。已填充部分为 `accent`，滑块为白色 + 1px 描边。始终与右对齐的等宽数字
读数配对，且同一组内每一行的读数宽度一致。

**下拉框。** 宽 200，单行，溢出省略号，右侧 chevron。下拉面板 `radius-panel` + `med` elevation；条目使用
`radius-control`（8）与 `hover_bg` 填充。显示文本必须本地化且面向用户；如果原始值对开发者有意义而对用户无意义
（VID/PID、preset key），显示可读名称，把原始值移到 caption 行。

**输入框。** `field_bg` + `radius-control`，高 32，焦点用内嵌 accent 环表示。

**颜色选择器。** 带描边的色块 + 十六进制值（`caption`）。绝不用裸渐变图形。

**Tooltip。** `radius-panel` + `med` elevation，14pt 文字，悬停延时后瞬时出现、瞬时消失。

**空态。** 居中的 `caption` 文字，`text_muted`；除非是首次运行界面（引导页），否则不配插图。

## 10. 交互状态

每个自绘控件都要有全部六种状态，且都使用上文的 token，不得引入新颜色：

| 状态 | 处理 |
| --- | --- |
| normal | 基础 token |
| hover | `hover_bg` 填充（瞬时，无过渡） |
| pressed | 填充型控件用 ~85% 的 accent；描边型用 `hover_bg` + 轻微内陷 |
| selected | `selection_bg` 填充，或卡片/色块使用 accent 环 |
| disabled | `text_disabled`，控件填充 50% 不透明度，无 hover 反馈 |
| focus（键盘） | 内嵌 accent 环，2pt，在 `card_bg` 与 `window_bg` 上都清晰可见 |

点击热区至少 28×28；纯文字入口要靠内边距补足。hover 与选中**绝不改变布局**（不改变尺寸、不改变字重），
只改颜色。

## 11. 无障碍与本地化

- 对比度：见 §3.3。调色板任何改动后都要重新测量。
- Reduce Motion：见 §8，强制。
- 每个自绘控件都通过 AppKit 设置无障碍标签与角色，使 VoiceOver 读到的信息与像素一致；数值型控件要读出数值。
- 所有用户可见字符串都走 `t()` / `tf()` / `t_count()`，并在**全部** locale（`en`、`zh-Hans`、`zh-Hant`）
  都有键。缺键会把 key 本身渲染出来，屏幕上绝不允许出现。
- 标签和控件值里绝不出现配置键、枚举名、十六进制值、VID/PID 或内部 preset 标识符；用户自己的颜色值仅可作为颜色选择器的说明文字例外显示。
- 布局必须在伪本地化（`--pseudo-locale`）和长文本 fixture 下存活：不裁切、不重叠、用户需要读的标签不被截断。
- 文字缩放：用户可调字号永远不改变行的**结构**（不因为字号而让行多出一行）。

## 12. 新增 token 或取值

1. 优先复用现有 token。如果两个角色需要「略微不同」的颜色，说明角色划分错了——先修角色。
2. 确实需要新值时，加在 `src/theme.rs` 里同类旁边，给语义化命名，并同时补齐浅色与深色。
3. 任何新文字颜色都要实测对比度，并记录到上面的表里。
4. 同一次改动里更新本文。**不在本文里的取值等于不存在。**

AppKit 字重值在 `theme.rs` 中命名：regular `0.0`、semibold `0.3`、bold `0.4`。中档 elevation 常量对应上表的
`med`；切换器选中环内缩为 §6 定义的 3pt。

- [ ] 视图构造函数里没有新增字面量颜色、字号、圆角、间距或时长。
- [ ] 新增/修改的文字角色，在它可能出现的每个 surface 上都满足对比度下限。
- [ ] 每个新字符串在 `en`、`zh-Hans`、`zh-Hant` 都有键；屏幕上没有原始标识符。
- [ ] 控件都是单行；长值截断并能看到完整值。
- [ ] 卡片用描边而非大范围阴影；elevation 档位与它实际浮在什么之上相符。
- [ ] 圆角来自三档尺度；派生圆角是计算出来的，不是写死的。
- [ ] 动画只使用两档时长与标准曲线，并处理 Reduce Motion。
